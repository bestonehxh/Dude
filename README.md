# Dude

Label studio for the **Brother PT-P710BT** label printer — cable labels (source ↔ destination)
and device names, printed over Bluetooth or USB.

**[Download the latest version](https://github.com/bestonehxh/Dude/releases/latest)** — unzip and move
`Dude.app` to Applications. Signed with Developer ID and notarized by Apple; it updates itself
(Dude ▸ Check for Updates…).

## Features
- Cable labels with both ends (`S:` / `D:`, each end lists its own name first) or device names
- Live preview that shows exactly what the printer will print, with measurements in mm
- Single or fold-over labels, 6–24 mm tape, auto-fitting text, alignment, padding
- Tick rows to print only those; print one row from its menu
- Paste rows straight from Excel or Numbers, import/export CSV, undo
- Check Printer reads the loaded tape width and explains printer errors
- Rows and settings are saved between launches

## Requirements
- macOS 27 or later on Apple Silicon
- Brother PT-P710BT, paired over Bluetooth or connected by USB
